1. download and install the latest node.js version
   -  https://nodejs.org/en/download/


3. download and install git to clone the project
   -  https://git-scm.com/downloads/win
      choose  "Git for Windows/x64 Setup."


4. install/create a github account (if you don't have one)
    copy the following url for our project:
   - https://github.com/jarifi/step-together-react-native

   click on the "Code" button and copy the following HTTPS:
   - https://github.com/jarifi/step-together-react-native.git


  4.1 open a new Window in Visual Studio Code and click on "Clone Git Repository" and paste the HTTPS
      - Select a Repository 

4.2. Go to Terminal and do a "npm install"


5. to rebuild the project use these following steps (can be started like this aswell):
    - npx expo install expo-clipboard
    - npx expo start -c
    - npm run start:dev

6. to start it you can also use:
   - npm run start:dev



7. Use Windows + R and type:
- chrome.exe --disable-web-security --disable-gpu --user-data-dir=%LOCALAPPDATA%\Google\chromeTemp

to use chrome with disabled web security to see our project


8. To have the phone version do these following steps:
    - (in dem chrom was du mit Win + R geöffnet hast)
8.1
    - Click on "Erwiterungen" or "extensions"
    - on the left there will be a clickable text called "Chrome Web Store"
    - search for "Mobiler Telefonsimulator" and add this
    - go to your opened project and with the right mouse click and click on the simulator you added
    - use the option "Mobile Ansicht in diesem Tab aktivieren"

now you have the phone version of our project
